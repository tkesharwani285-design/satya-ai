# Satya.ai

Single-file React + Tailwind app (loaded from CDNs, no build step).

## Run
Open `index.html` in a browser (needs internet for the React, Babel and Tailwind CDN scripts).
Or serve locally: `python3 -m http.server 8000` then visit http://localhost:8000

## Notes
- All analysis results, login and the human check are simulated demo data.
- Icons are inline SVGs in the Lucide style.
